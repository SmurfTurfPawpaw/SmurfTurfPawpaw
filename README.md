## Selected work

- [Intelligence Is Not Enough](https://github.com/SmurfTurfPawpaw/intelligence-is-not-enough) — A portable Python harness that ties tasks, files, checks and reviews to exact versions. It flags changed inputs and stale evidence.
- [GATE](https://github.com/SmurfTurfPawpaw/GATE) — A CLI and private web cockpit for scoped AI and security work. The public foundation is under active development.
- [Hives CSV core](https://github.com/SmurfTurfPawpaw/hives-csv-core) — Exact-key CSV comparison that leaves duplicate keys for review instead of guessing. See the [browser tool](https://hives.gent/tools/compare-csv).
- [Manual](https://github.com/tatter-xyz/manual) — I built the local HTTP/API evaluation pilot and am developing the wider benchmark with Tatter.
- [SafeSpace → ATENA Space](https://giovannicallebaut.com/blog/atena-power-in-orbit/) — Earlier IoT, data-path and business work that became the precursor to ATENA.
- I also built a private evidence reader that joins PDFs, email and chat in a searchable SQLite index.
