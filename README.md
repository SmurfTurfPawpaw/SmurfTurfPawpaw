# Giovanni Callebaut

I build software and AI systems: agent harnesses, developer tools and source-linked data apps. Based in Ghent, Belgium.

I work across the interface, data flow, tools, tests and release. I like systems where someone else can see what happened, trace the result and pick up the work.

## Selected work

| Project | What I built | Stage |
